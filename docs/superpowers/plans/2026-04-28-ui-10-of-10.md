## Task 3: Score Count-Up

**Goal:** The "34 / 100" score text in the hero mock card animates from 0 to 34 on mount.

**File:** `src/App.tsx` — `LandingPage` component

- [ ] **Step 1: Add count-up hook inside LandingPage**

After the `scanCount` state/effect block, add:
```tsx
  const [heroScore, setHeroScore] = useState(0);
  useEffect(() => {
    const target = 34;
    const duration = 1200;
    const start = performance.now();
    const raf = (now: number) => {
      const t = Math.min((now - start) / duration, 1);
      const eased = 1 - Math.pow(1 - t, 3); // ease-out cubic
      setHeroScore(Math.round(eased * target));
      if (t < 1) requestAnimationFrame(raf);
    };
    const id = requestAnimationFrame(raf);
    return () => cancelAnimationFrame(id);
  }, []);
```

- [ ] **Step 2: Replace static score in mock card (~line 728)**

Find:
```tsx
                  <span className="text-rose-400 font-black text-sm">34 / 100</span>
```

Replace with:
```tsx
                  <span className="text-rose-400 font-black text-sm tabular-nums">{heroScore} / 100</span>
```

## Task 4: Animated Pillar Bars

**Goal:** Pillar bars in the hero mock card wipe in from 0 with staggered delay on mount.

**File:** `src/App.tsx` — hero mock card pillars section (~lines 736-752)

- [ ] **Step 1: Add inView state for pillar animation**

In `LandingPage`, after the `heroScore` state, add:
```tsx
  const [pillarsVisible, setPillarsVisible] = useState(false);
  const pillarsRef = useRef<HTMLDivElement>(null);
  useEffect(() => {
    const el = pillarsRef.current;
    if (!el) return;
    const obs = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) { setPillarsVisible(true); obs.disconnect(); }
    }, { threshold: 0.3 });
    obs.observe(el);
    return () => obs.disconnect();
  }, []);
```
